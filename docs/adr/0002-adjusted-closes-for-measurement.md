# Adjusted closes for measurement, raw closes for execution

Market data stores "raw" closes so SL/TP detection matches the prices the trader actually saw. These are Yahoo's `Close` with `auto_adjust=False`, which is split-adjusted but not dividend-adjusted: a bar from before a split shows the price divided by the split ratio, while dividends leave it untouched. Long-window measures (Basket Indexes, the Momentum Score) break on these closes because dividends look like losses. We store Yahoo's adjusted close (split- and dividend-adjusted) alongside the raw one and use it only for measurement; SL/TP detection and Portfolio Value keep using raw closes, since they deal in real prices and real units. Because the raw closes are split-adjusted, a Portfolio applies each instrument's split events automatically, expressing Lots bought before a split in the same split-adjusted units as the closes. Yahoo restates both closes retroactively on every new split (and the adjusted close on every new dividend), while sync only fills date gaps; so when a sync brings in a split not yet stored or a dividend, it re-fetches that instrument's whole stored range and overwrites it, keeping the stored series fully restated to the latest basis.
